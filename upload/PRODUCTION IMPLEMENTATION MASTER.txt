9. VIDEO STORAGE
============================================================

NEVER store video files in PostgreSQL.

Use Azure Blob Storage for production video storage.

Upload architecture:

Browser
→ API
→ authentication/RBAC
→ metadata validation
→ generate short-lived write SAS
→ browser uploads directly to Blob
→ upload-complete API
→ database record
→ PROCESSING
→ READY / FAILED

Playback architecture:

Browser
→ authenticated API
→ authorization
→ database metadata
→ generate short-lived read SAS
→ browser streams video directly from Blob Storage

Do not proxy large video files through the Next.js server.

Validate:

- MIME type
- extension
- file size
- duration where technically available/appropriate

MVP:

- .mp4
- .webm
- maximum duration: 10 minutes
- maximum file size: 500MB

Keep these limits configurable.
